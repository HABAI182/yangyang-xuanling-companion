# 秧秧玄翎 0.3.2

左侧发梢在原始画布边缘形成直切。新增不超过16源像素的弧形补片，颜色从相邻原图像素局部延展，左右各24像素透明余量用于完整显示。原图重合区域的中性画面RGBA保持不变，不改变长宽比例或整体色彩。

文字泡与按键浮显保留同一20%高度。两者改为雾蓝边框、浅色内框、细金色点缀；按键默认130%大小。设置的“按键浮显”和“陪伴与回应”分别提供80–180%、80–160%的独立缩放；旧设置自动补充新默认值，桌宠大小和其他选项保留。

视线默认幅度为原来的165%，提供50–250%独立调整。虹膜始终受已有原生眼白遮罩限制。菜单中的17种表情逐项调整：嘴形、局部眼睑/睫毛形变、虹膜形态、脸颊色及细小泪光参与表现；害羞使用单侧闭眼和低垂视线，得意使用另一侧眨眼，大笑双眼闭合并张口。开心、认真、生气、无奈、委屈等嘴形和眼睑差异不再只依赖外部符号。每个菜单情绪也对应相符的短句。

技术边界：原生CMO3、MOC3和贴图继续使用v11真实导出，未重写专有模型文件。本轮发梢/嘴部补片和眼睑细调属于SDK运行时效果，补片通过缓存的重心坐标跟随真实头部三角形。新增 `YangyangXuanling-Details-v12.psd` 是可编辑补充素材，不能冒充已导入的原生模型。嘴形矢量源在 `src/face-art.ts`；中性姿势保持原来的嘴。眨眼仍使用独立闭眼图，尚未制作连续闭合几何与完整原生口形参数。

验收分为单元、真实Core/WebGL、像素遮罩、打包Windows窗口和用户观感。渲染成功不等于用户已经认可美术。键鼠原生钩子未改变，本轮不重复要求用户做物理长按测试。验收记录见 `validation-0.3.2.json`。旧版目录和标签保持不变。
