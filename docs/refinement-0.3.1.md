# 0.3.1：双眼遮罩与回弹修复

双眼转向时，旧版圆形裁口会露出白色月牙；表情还会缩放带有睫毛和头发的粗裁片，造成重影。v11 将 `eye-left/right` 改为固定眼白遮罩，`iris-left/right` 改为有完整隐藏边界的独立瞳孔。Cubism 原生剪贴关系为 `ArtMesh4 → ArtMesh6`、`ArtMesh5 → ArtMesh7`。睫毛、眼缘和附近头发回到固定头部。

保留原图比例、灰蓝瞳色和非眼区域可见像素。眼内已有像素按轮廓保留，只清理污染边缘、补全眼皮遮住的边界；没有重新生成整张图。图像差异和裁片检查见 `eye-masks-v11.json`。

输入响应增强按下压缩、松开拉伸、手掌按压及小鸟响应。去掉头部回弹与键盘手按压之间的混合，修复鼠标单击瞬间另一只手轻微跟着按压的问题；新增按下约 65ms 时另一只手原生按压参数必须为零的检查。真正松开才补一次回弹；系统重复输入不补能量，快速敲击的幅度有界。头部、眼白和瞳孔使用同一变换，脸颊装饰跟随相应的脸部位置。按键浮显保持原高度；文字气泡改为相同的 20% 高度并从左侧 12% 移到 3%。脸红改为渐隐晕染和短笔触。

## 源文件和运行时

- 可编辑源：`art/source/YangyangXuanling-v11-rig.cmo3`；PSD：`art/source/YangyangXuanling-Separated-v11.psd`。
- 官方导出：`public/models/yangyang-v11/YangyangXuanling.model3.json`；13 个网格，27 个参数，4096×2048 图集。
- 原生绑定：双手按压、开闭眼透明度、眼白剪贴遮罩。
- SDK 运行时：二维视线、四区与 Space 伸手、鼠标联动、阻尼形变、小鸟及部分表情装饰。旧水平瞳孔几何键已由二维运行时视线替代，避免双重位移。
- `native_eye_masks_v11.py` 直接使用官方 1.1 API 执行有备份、读回和回滚检查的局部事务。现有 MCP 缺少该配方；PSD 导入、Auto Mesh、贴图集仍由真实 Editor 完成。

## 验证

CMO3 保存并重开后，全部对象绑定一致。官方 SDK 的双手和闭眼三例通过。浏览器检查覆盖五个按键区、视线四角、独立鼠标/鸟、弹动和回到中性；输入单测 9 项通过。

独立眼部检查冻结头部及鼠标衣袖位移，避免无关位移影响像素比较：六个姿势在眼白遮罩外 5 像素保护带以外的眼区没有像素移动，眼区没有透明洞。该检查证明遮罩约束，不能代替人的美术评价。

Windows 最终 EXE 可见且持续绘制，双眼开闭、小鸟动作、新模型 MOC3/贴图哈希和设置保留检查通过。0.3.1 没有再次要求用户长按实测；物理输入证据仍是 0.3.0，新的弹簧时序由单测和 WebGL 检查覆盖。

闭眼仍是独立闭眼图切换；尚无连续眼皮几何、独立口形和发丝物理。详细范围和未测项见 `validation-0.3.1.json`。旧交付、旧模型和 tag 保留；仅在私有仓库管理。

原生遮罩方法依据 [Live2D 官方剪贴文档](https://docs.live2d.com/en/cubism-editor-manual/clipping-mask/)；所用属性与参数事务依据 [官方编辑 API](https://cubism.live2d.com/editor-alpha/doc/manual/alpha1/zh/external-api-intergration/index.html)。
