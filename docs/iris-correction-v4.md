# 灰蓝瞳色修正 v4

用户指出 v3 瞳色太青，因此撤销该版作为当前配色。v4 从未改色的 v2 原像素重新计算，色相上部约 224°、下部约 215°，饱和度保留原来的 50%–70%，压低上部亮度，保留原眼形、高光、睫毛和淡金色细下缘。避免对上次结果叠加处理。

这是用户明确反馈后的灰蓝二创配色，不声称是官方发布的精确色值。官方参考和原始 v2、偏青 v3 均已保留。掩码外像素变化 0、透明度变化 0；1536×1536 可见原像素没有缩放。静止合成与 v4 输入差异 0。10 层 PSD 为 `art/source/YangyangXuanling-OfficialIris-v4.psd`，当前程序预览引用 `public/assets/v4`。

视觉对照：`art/iris-before-after-v4.png` 左为 v3、右为 v4。尚待真实 Cubism 动作绑定、官方导出及目标 Windows 实机验收。
