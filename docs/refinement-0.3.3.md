# 秧秧玄翎 0.3.3

本版同时完成闭眼轮廓覆盖、Q版情绪符号、统一气泡边框、菜单收高、扩大视线与静止回正，以及透明区域点击穿透。保留用户原图比例、灰蓝瞳色、左侧鼠标/右侧键盘归属、当前353左右逻辑像素的显示大小及其他既有选择。

在设置→外观的动作观感中，视线默认210%（可调50–320%），新增静止回正开关与1–15秒等待时间，默认3秒、850ms平滑回正。鼠标在桌宠矩形外移动也算活动；回正仅影响眼睛/头部的视线目标，鼠标和手掌维持独立目标。

透明轮廓以实际WebGL帧与网格补片的alpha构造，65ms采样、原生8ms轮询切换整窗鼠标接收，不修改显示轮廓或裁切动作。只有可见主体与底部三个按钮命中，空白和内孔可点到后方。细边约一个采样像素容差，按住按钮或拖动时不改变捕获。首次Windows探测出现一次底部命中不符，未记录指针是否被外部移动，因此不武断归因；加入实际指针位置校验后，完整8点连续3轮通过。测试未证明移动和点击发生在同一8ms采样周期内的零延迟命中。

困倦、大笑和单侧闭眼覆盖原大眼睫毛与外眼角，沿用本项目冻结的局部隐藏补绘，不重画全身。闭眼仍采用独立图层切换；本轮是网格附着运行时修复，没有修改原生v11的CMO3/MOC3/贴图。掩码外源像素变化0，补充PSD为Details-v13。连续几何闭合、完整原生口形和精细发丝物理仍保留后续边界。

惊讶、困倦、思考等符号使用手绘矢量轮廓与深蓝/奶白双描边；消息泡和按键框共用加粗雾蓝框、蓝白羽毛、金花和红绳。两者高度维持20%，大小仍可分别设置。菜单默认收合、展开更多情绪才加高；原生窗口在150% DPI下随内容收放，底部只留正常内边距。

前端15项、Rust16项测试通过。真实Core/WebGL检查涵盖闭眼、单眼、符号、统一框、静止回正与独立手掌、四区和Space、弹簧复位及原生眼白遮罩；Windows最终EXE资源哈希、菜单与设置保存、眨眼复位、鸟动作和透明点击均通过。自动化是本机合成输入，用户物理按键、游戏/手柄、安装流程等未重新宣称验收。用户美术观感仍待其评价。
