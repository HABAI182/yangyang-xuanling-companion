## 原生模型与运行时的分工

原生13个 ArtMesh：独立左右手掌、固定袖根、鼠标、键盘、玄翎雀、头身、双眼底、双瞳孔、双闭眼线。双手分别绑定 ParamBodyAngleX/Y，眼开闭0/1透明度切换，双瞳孔 ParamEyeBallX 的 -1/0/1 几何键。原生Y视线、发丝物理、独立口形尚未制作。

`src/model-motion.ts` 在真实 Core 输出上做可恢复的顶点变形：四区和Space的二维伸手、局部袖根连接、鼠标和手掌相同有界平移、垂直视线、头部压缩回弹、鸟身摇摆跳跃和尾部滞后。每帧先恢复 Core 顶点，防止累积拉伸。头部冲量有界，袖口逐渐锚定桌面，避免回弹拉断手腕。认真/生气等眼形压缩与惊讶瞳孔缩放也属于运行时效果；17个情绪入口仍有SVG装饰，不等同于17套原生脸部模型。

四区覆盖物理键盘与扩展键，Space单独；当前仍按住的最后一个新键决定落点，松Space返回仍按住的键。系统长按重复只产生可选浮显，不添加弹簧能量。屏幕右手/角色左手敲键盘，屏幕左手/角色右手控制鼠标。
