# 0.3.7 静态桌面版与直接EXE交付

静态版以现有0.3.6基础版的透明日常渲染作为固定画面，PNG原字节复用，没有压缩比例、改色或重绘。素材来源及SHA256见 `public/assets/static/provenance.json`。

## 版本

| 版本 | 软件版本 | 本轮变动 |
| --- | --- | --- |
| 静态桌面版 | 0.3.7 | 新增独立Windows x64 EXE |
| 免费基础版 | 0.3.6 | 原始EXE新增独立下载入口，字节不变 |
| 表情完整版 | 0.3.6 | 原始EXE新增独立下载入口，字节不变 |

静态画面不眨眼、不跟随鼠标、不敲击键鼠、不切换表情，不启动Live2D Core、模型或持续动画绘制。保留缩放、拖动、置顶、轮廓穿透、整只穿透、位置预设、托盘、找回窗口和登录启动。原生层只保留桌面轮廓、鼠标拖动及找回快捷键的必要处理，不安装全局键盘钩子，不记录键盘输入。

使用独立的 `.static` 配置目录与 `YangyangXuanlingStatic` 启动项，不能覆盖互动版设置。旧设置或IPC不能重新打开静态版的动作、视线、表情、声音和按键浮显。

## 验证边界

前端19项测试通过；Rust三种功能组合各18项测试通过。静态版浏览器和原生EXE均检查了画面像素在键盘、鼠标与表情指令后保持不变，且无Core/模型请求。原生EXE启动可见、缩放、无表情菜单、精简设置和轮廓IPC已验；原生后端会拒绝情绪动作并清理恢复设置中的动态功能。测试后核对并恢复用户配置。

没有把注入测试称为真实物理桌面点击验收；本轮未执行安装器，也不代表跨DPI、多显示器全场景已验。此前角色营利许可和爱发电审核状态不因新增静态版而改变。
